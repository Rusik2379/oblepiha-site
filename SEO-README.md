# SEO сайта

Основной адрес: `https://oblepiha-22.ru/` (домен с предоставленного скриншота Google Search Console). Метаданные десяти публичных страниц задаются в `server/seo.mjs`. После изменения запустите `node tools/update_seo.mjs`: обновятся HTML и статическая резервная карта сайта. Шаблоны шапки и подвала синхронизируются отдельно; SEO не меняет их дизайн.

На каждой странице есть отдельные title, description, canonical, Open Graph и карточка для соцсетей с подходящей фотографией. JSON-LD описывает гостиницу, адрес и телефон, сайт, страницу и навигационную цепочку. Оценки, отзывы, звёздность, цены и часы работы в разметку не добавлялись без подтверждённых данных.

Node.js отдаёт главную ленту, список новостей, отдельные публикации и опубликованные вакансии уже в HTML. Поэтому содержимое доступно без выполнения JavaScript. У каждой публикации — собственный canonical, описание, изображение и разметка BlogPosting. Отсутствующая или удалённая публикация возвращает HTTP 404 и noindex. Скрытые вакансии не попадают в HTML или публичный API.

`/sitemap.xml` формируется из актуальных данных, включая отдельные новости и даты их изменения. `robots.txt` закрывает административный API и служебные каталоги; редактор дополнительно отдаёт noindex. Caddy в самостоятельной конфигурации перенаправляет www на основной домен и /index.html на /. HTTPS и сжатие включены в конфигурации развёртывания.

У растровых изображений в HTML добавлены исходные размеры, сохраняется отложенная загрузка нижних изображений. Фото детского уголка в кафе заменено на реальную игровую зону в WebP с описательным alt. Макет и адаптивные размеры сохранены.

SEO-обновление опубликовано 2 октября 2026 года в `/opt/projects/sites/oblepiha-site`: отдельная разметка услуг и оптимизированные изображения работают на основном домене. Все десять публичных страниц, HTTPS, robots.txt, карта сайта и перенаправления www и /index.html проверены по HTTP. Пользователь предоставил счётчик Метрики 113281307; analytics-config.js настроен на этот номер, Вебвизор, карту кликов и отслеживание ссылок согласно присланному коду. Отчёт, цели и дальнейшие действия находятся в `SEO-NEXT-STEPS.md`. В Яндексе sitemap отправлен; ошибку получения Sitemap в Google ещё нужно перепроверить. Технические изменения не гарантируют позиции в поиске.

Использованы рекомендации Google: [JavaScript SEO](https://developers.google.com/search/docs/crawling-indexing/javascript/javascript-seo-basics), [канонические адреса](https://developers.google.com/search/docs/crawling-indexing/consolidate-duplicate-urls), [разметка локального бизнеса](https://developers.google.com/search/docs/appearance/structured-data/local-business), [правила структурированных данных](https://developers.google.com/search/docs/appearance/structured-data/sd-policies).
