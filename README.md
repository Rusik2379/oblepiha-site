# Гостиничный комплекс «Облепиха»

## Новая версия сайта

Текущий редизайн находится в папке [`redesign/`](redesign/README.md). Он сохранён отдельно от прежнего сайта и пока предназначен для локального просмотра.

Из корня проекта:

```sh
node redesign/build.mjs
node redesign/preview.mjs
```

Открыть <http://localhost:8766/>.

На главной выбраны первый вариант первого экрана (Cormorant Garamond) и первый вариант знакомства с комплексом (две фотографии без наложений). Сохранены настоящий TravelLine, галереи категорий номеров, страницы услуг и адаптация для телефона.

В [`redesign/README.md`](redesign/README.md) описаны структура, сборка и страницы сравнения дизайна.

## Прежняя версия

Файлы в корне, `assets/`, `shared/` и `server/` относятся к прежнему сайту и его общим ресурсам. Новая версия использует фотографии и шрифты из `assets/`.

Инструкции для прежнего размещения — [`DEPLOY.md`](DEPLOY.md); управление новостями — [`NEWS-README.md`](NEWS-README.md). Загрузка в GitHub сама по себе не переносит редизайн на основной домен.

Пароли, переменные окружения, локальная база админки и экспорты исключены через `.gitignore`. Для развёртывания настройки и данные сервера нужно переносить отдельно.
